## 📦 Projects Overview

Here is a summary of the 9 production-grade projects showcased on my portfolio. 

> [!NOTE]  
> The source code for these projects is kept in **private repositories** for intellectual property protection. However, you can explore the full interactive walkthroughs, feature specifications, and screen breakdowns on the live portfolio site.

### 1. [MedTrack](https://abh1shek017.github.io/portfolio/projects/medtrack.html) 💊

- **Type:** Pharmacy Management (Full-Stack)
- **Tech Stack:** Flutter, Riverpod, Drift (SQLite), FastAPI, PostgreSQL, Alembic, Docker, Firebase
- **Summary:** An offline-first, back-office procurement and inventory management system designed for independent pharmacy owners. Tracks medicine batches, expiries, B2B wholesale clinic channels, and retail credit (Udhaar) ledgers with full audit tracking.

### 2. [AgriSense AI](https://abh1shek017.github.io/portfolio/projects/agrisense.html) 🌾

- **Type:** IoT + ML Crop Recommendation
- **Tech Stack:** Flutter, React.js, Flask, scikit-learn, ESP32 IoT, MQTT, D3.js, Leaflet, NASA POWER API
- **Summary:** An end-to-end cyber-physical agriculture platform. Fuses real-time physical sensor data (NPK, pH, moisture) with satellite/climate APIs to predict crop suitability via an ensemble ML voting model. Includes GPS field mapping and daily irrigation schedulers.

### 3. [AeroPrompt](https://abh1shek017.github.io/portfolio/projects/aeroprompt.html) 🚀

- **Type:** AI Prompt Optimizer (Browser Extension)
- **Tech Stack:** Next.js, React, TypeScript, Plasmo, FastAPI, Python, Supabase, Docker, Google Cloud Run, Razorpay
- **Summary:** An AI prompt optimization extension and dashboard website. Intercepts inputs on ChatGPT, Claude, and Gemini to enhance them dynamically via an LLM optimization backend, with integrated user analytics and payments.

### 4. [The Manager](https://abh1shek017.github.io/portfolio/projects/manager.html) 💼

- **Type:** Developer Operations Cockpit (AI Console)
- **Tech Stack:** Next.js 15, App Router, TypeScript, Tailwind CSS, FastAPI, SQLModel, PostgreSQL, SQLite, Groq SDK
- **Summary:** A self-hosted developer operations dashboard to track projects, tasks, milestones, and credentials. Combines a keyboard-first Omnibar with a natural language Llama 3 processor (Groq API) for AI command dispatching.

### 5. [UrbanLeafs](https://abh1shek017.github.io/portfolio/projects/urbanleafs.html) 🌿

- **Type:** Business Operations Management
- **Tech Stack:** Flutter, Riverpod, Firebase (Firestore, Auth, Storage), Go Router, Material Design 3
- **Summary:** An enterprise resource management dashboard for SMEs. Facilitates employee shift attendance logging, live stock metrics, order processing state trackers, and live balance sheet reporting.

### 6. [ReBalance](https://abh1shek017.github.io/portfolio/projects/rebalance.html) 🌟

- **Type:** Digital Wellness (Android)
- **Tech Stack:** Flutter, Provider, Hive, Android UsageStats API, Local Notifications, Overlay Windows, FL Chart
- **Summary:** A screen-time gamification app. Converts foreground device usage into "digital calories" with multipliers and penalties, enforces app-blocking overlays, and recommends contextual physical actions (mindfulness, exercise) to improve focus.

### 7. [NextMove](https://abh1shek017.github.io/portfolio/projects/nextmove.html) 🚗

- **Type:** ML mobility prediction and trip tracking
- **Tech Stack:** Flutter, Provider, Geolocator, Sensors Plus, FastAPI, PostgreSQL, Twilio, scikit-learn
- **Summary:** Continuous travel logger that automatically classifies transit modes (walking, driving, cycling) using on-device accelerometer/gyroscope readings and GPS paths mapped over custom background services.

### 8. [Logic Grid](https://abh1shek017.github.io/portfolio/projects/logic-grid.html) 🧩

- **Type:** Strategy Game
- **Tech Stack:** Flutter, Provider, Hive, Supabase, Google Play Games Services, Google AdMob, AudioPlayers
- **Summary:** A grid-based puzzle/strategy mobile game incorporating Supabase progression sync, seasonal events, achievements, leaderboards, and audio track engines.

### 9. [Duel Fights](https://abh1shek017.github.io/portfolio/projects/duel-fights.html) 🎮

- **Type:** Local Multiplayer Game
- **Tech Stack:** Flutter, Flame Game Engine, Nearby Connections API, Permission Handler
- **Summary:** A real-time pong combat game powered by Google's Nearby Connections API for offline Bluetooth and WiFi Direct peer-to-peer multiplayer rendering.
