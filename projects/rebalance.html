About ReBalance

ReBalance is a native Android application designed to help users establish mindful phone usage patterns and break screen addictions. Built with Flutter, it interacts with Android system services to collect application usage statistics and monitors app usage in the foreground every 2 seconds. State management is handled with Provider, ensuring smooth updates across charts, timers, and calorie counts.

The app introduces a unique gamification system called "Digital Calories". Each minute of app usage is converted into a score, scaled by category multipliers (Social Media 2.0x, Gaming 2.2x, Education 0.6x) and penalties (1.5x multiplier for late-night screen time). Users can set limits on screen time, blocking apps that exceed their allowances using custom overlay draw permissions.

Key Modules & Features

  • 📊
    Usage Monitoring: Hooks into the Android UsageStats API to track foreground apps, active durations, and session transitions in real time.
  • 🔥
    Digital Calorie System: Gamifies screen time by converting minutes into "calories" based on category weightings and late-night penalties.
  • ⏰
    App Limiting & Overlays: Set limits on specific apps. If limits are reached, the app uses system overlay draw rules to block further interaction.
  • 🔔
    Smart Notifications: Contextual alerts (warnings, limits reached, consecutive usage warnings) utilizing local notifications.
  • 🎯
    Mindful Suggestions: Recommends healthy physical activities (Mindfulness, Reading, Exercise) based on current usage phases.
  • ⚡
    Streak Trackers: Incorporates streak tracking and rewards to motivate consistency in completing physical activities.
