About Duel Fights

Duel Fights (also known as Bluetooth Brawlers) is a real-time multiplayer Pong-style game designed for close-proximity competition. Built with Flutter, it utilizes the Flame game engine for 2D rendering, ball collision physics, and smooth rendering performance at 60 FPS.

The core feature is local multiplayer. It integrates Google's Nearby Connections API, allowing devices to establish low-latency connections over Bluetooth or WiFi Direct without requiring an active internet connection. Players can join lobbies, select game modes, and play local or offline single-player matches.

Key Modules & Features

  • 🎮
    Multiplayer Match: Real-time Pong-style gameplay using Flame engine rigid body physics and rendering.
  • 📶
    Nearby Connections: Local multiplayer over peer-to-peer Bluetooth and WiFi Direct with Nearby Connections API.
  • 🤖
    Offline Mode: Play against built-in AI controllers with adjustable difficulty settings.
  • 🤝
    Lobby Matchmaking: Search and connect with nearby devices using discoverable profiles.
