About MedTrack

Problem

Independent pharmacies track medicine batches and expiry dates, distributor balances, and informal customer credit across separate records.

Solution

A back-office app covering procurement, batch-level stock, supplier payments, B2B invoicing, and a credit ledger.

Engineering

Built with Flutter and Riverpod using an offline-first architecture powered by Drift (SQLite). Local data syncs to a Python/FastAPI backend with PostgreSQL, Alembic migrations, and Docker, hosted on Oracle Cloud Infrastructure (OCI). Implements biometric login, email OTP 2FA, device-session revocation, and Gemini API for bill parsing. Supports Admin and Staff roles.

Core Modules

  • 📦
    Offline-first inventory: Drift/SQLite local database with full offline read/write capability.
  • 🏷️
    Batch & expiry tracking: Track medicine batches with custom expiry dates, MRP, purchase rates, and quantities.
  • 🤝
    Supplier ledger: Log distributor invoices, track outstanding balances, and record settlement payments.
  • 🏪
    B2B invoicing: Sell to clinics and shops with DL/GSTIN validation and automated stock decrementing.
  • 📓
    Credit tracking: Log informal customer credit (Udhaar) and repayments.
  • 📄
    Reports & analytics: Generate low-stock alerts, expiry notifications, spend analysis, and PDF exports.

All Modules & Features

  • 🤖
    AI bill parsing (Gemini): Extract product, batch, and pricing details from supplier bills using Gemini API.
  • 💸
    Expense Tracker: Log utility, rent, maintenance, and salary payouts to monitor daily shop cashflow.
  • ⚡
    Smart Sourcing: Create draft orders with automated scoring to suggest suppliers based on purchase history.
  • 🔍
    Global Search FTS5: Offline SQLite full-text search across products, invoices, and customers.
  • 🛡️
    Authentication & Access: Biometric login, email OTP 2FA, device-session revocation, and Admin / Staff role-based access.
  • 📱
    Barcode Scanner: Barcode scanning for product identification and inventory management.

Technical Highlights

  • Offline-first local database (Drift/SQLite)
  • REST API (FastAPI) with PostgreSQL and Alembic migrations
  • Riverpod state management
  • Gemini API bill parsing
  • Biometric login, email OTP 2FA, device-session revocation
  • PDF generation
  • Barcode scanning
  • FTS5 offline search
  • Dockerized backend hosted on Oracle Cloud Infrastructure
