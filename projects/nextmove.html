About NextMove

NextMove is an intelligent mobility tracking system designed to automatically analyze and classify user travel patterns. The system consists of a Flutter mobile application and a Python FastAPI backend. It utilizes motion sensors (accelerometer, gyroscope) and GPS coordinates captured on the device to predict travel modes like walking, cycling, or driving.

To enable continuous tracking, the Flutter app utilizes custom background service wrappers that record location and movement patterns even when the phone is locked. The recorded data streams to a FastAPI backend endpoint, where a machine learning model computes mode classifications. Security and authentication are managed through phone-number-based OTP codes verified via Twilio integration.

Key Modules & Features

  • 📍
    GPS Telemetry: Real-time location tracking using the Geolocator library, with background updates for continuous path recording.
  • 🤖
    ML Mode Detection: Collects motion sensor readings to classify transportation types (walking, driving, cycling) in real time.
  • 🗺️
    Interactive Maps: Renders active paths, speed indicators, and historical trips on offline-capable OpenStreetMap layers.
  • 🛡️
    OTP Authentication: Secure onboarding utilizing phone numbers and Twilio OTP SMS verification.
  • ⚙️
    Background Services: Executes foreground logging routines with persistent notification cards to prevent OS terminations.
  • 📈
    Data Analytics: Visualizes trip statistics, speeds, durations, and historical modes through responsive charts.
