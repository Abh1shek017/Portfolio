About AgriSense AI

AgriSense AI is an end-to-end smart agriculture solution designed to transition farming from traditional rules-of-thumb to high-precision empirical data. The system features a simulated IoT hardware tier built with ESP32 (simulated in Wokwi) which captures soil NPK values, pH, moisture levels, and atmospheric metrics. This telemetry is streamed via MQTT to a Python Flask backend.

The core ML prediction engine fuses the physical sensor inputs with geospatial data fetched dynamically from NASA POWER, SoilGrids, and Open-Meteo. An ensemble voting classifier (comprising Random Forest, Support Vector Machine, and Multi-Layer Perceptron) processes this data to recommend the most suitable crop with statistical confidence levels. The project provides an interactive React.js web dashboard with GPS zone mapping, and a native Flutter mobile app featuring local caching via Hive and Firebase push anomaly warnings.

Key Modules & Features

  • ⚡
    IoT Data Acquisition: Telemetry capturing NPK, pH, moisture, and temperature using simulated edge microcontrollers.
  • 🗳️
    Ensemble Machine Learning: Combines Random Forest, SVM, and Neural Network (MLP) weights for crop suitability predictions.
  • 🗺️
    GPS Field Zoning: Interactive Leaflet map layout allowing farmers to outline fields and map soil profiles.
  • 🌦️
    Weather Integration: 14-day local agricultural forecasting coupled with NASA historical solar metrics.
  • 🔄
    Crop Rotation Planner: A 4-season rotation tool recommending sequences that prevent soil nutrition exhaustion.
  • 💧
    Water Budget Optimizer: Daily irrigation recommendations utilizing local evapotranspiration calculation rules.
  • 📦
    Offline Caching (Mobile): Local database storage on mobile using Hive to protect accessibility in weak network locations.
  • 🔔
    Push Warnings: Immediate alerts sent via Firebase Cloud Messaging if field thresholds indicate critical drought or acidity.
