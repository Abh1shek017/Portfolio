About Logic Grid

Logic Grid is a grid-based puzzle and strategy mobile game built with Flutter. Designed for single-player problem-solving, it features a progression of challenging grid levels. State management is handled with Provider to synchronize game state, board inputs, and UI states.

The architecture uses Supabase for cloud sync, saving player progression, level completions, and rewards across devices. It integrates Google Play Games Services to support global achievements and leaderboards, Google AdMob for monetization, and AudioPlayers for background tracks and dynamic sound effects.

Key Modules & Features

  • 🧩
    Grid Gameplay: Interactive grid levels, measuring solve times, moves, and board configurations.
  • 🤖
    Algorithmic Usernames: Generates unique player identities during onboarding using automated vocabulary lists.
  • ☁️
    Supabase Cloud Sync: Syncs game progress, completed levels, and profile settings using Supabase endpoints.
  • 🏆
    Play Games Integration: Tracks player achievements and manages leaderboards via Google Play Games Services.
  • 📅
    Seasonal Events: Access limited-time challenges and levels dynamically served from the cloud.
  • 🎵
    Dynamic Audio: Sound effects and background tracks managed through low-latency audio players.
