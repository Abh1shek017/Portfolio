About UrbanLeafs

UrbanLeafs is a comprehensive mobile solution engineered to digitize and manage daily operations for small and medium-sized enterprises (SMEs). Developed using Flutter with Riverpod for reactive state management, the application provides business owners with instant visibility into employee actions, inventory flows, and sales statistics.

The architecture connects directly to Firebase services, using Cloud Firestore for low-latency operational sync, Firebase Authentication for secure email/password credential management, and Cloud Storage for file attachments. The user interface uses Material Design 3 specifications with dark/light visual settings, localization rules, and responsive grid layouts designed to operate smoothly on varied tablet and smartphone viewports.

Key Modules & Features

  • 🏠
    Real-time Dashboard: Get instant metrics on daily attendance, pending orders, revenue receipts, and operational expenses.
  • 👥
    Attendance Tracking: Track shift presence (morning, afternoon) for workers with present/absent/half-day indicators.
  • 📦
    Inventory Control: Real-time stock counts, multi-unit layouts (kg, pcs, liters), and alert boundaries for low stock.
  • 📋
    Order Management: Log consumer requests, track workflow state (pending, ready, shipped), and link transactions to user records.
  • 💰
    Payment Trackers: Record incoming cash or digital payments, link transactions to customer bills, and track revenue.
  • 💸
    Expense Logging: Categorize outlays (raw material, labor, logistics, utility) and generate spending analysis reports.
  • 📊
    Live Balance Sheets: Financial logs that display overall margins, customer-wise transactions, and filterable audit paths.
  • 👤
    Access Controls: Role-based parameters classifying Admin actions from standard user functionalities.
