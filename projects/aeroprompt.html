About AeroPrompt

AeroPrompt is a comprehensive utility designed to optimize user prompts on popular AI interfaces (ChatGPT, Claude, and Gemini). Available as both a browser extension and a companion dashboard, the application handles prompt rewriting dynamically on the client side using a secure backend AI pipeline.

The Chrome extension is built on the Plasmo browser extension framework using React and TypeScript, allowing it to inject custom script overlays directly into LLM text areas. These script overlays intercept user entries, stream conversation history to calculate context relevance, append personalized user bio directives, and allow real-time tone adjustments (Professional, Persuasive, Concise). Telemetry is handled by a Dockerized FastAPI service deployed on Google Cloud Run, supported by Supabase for DB storage and payment configurations via Razorpay checkout webhooks.

Key Modules & Features

  • ⌨️
    Smart Enter: Intercepts your Enter key to optimize prompts directly on the fly. Press Enter once to optimize, and again to send.
  • 🧠
    Context Awareness: Analyzes conversation history on ChatGPT/Claude to ensure optimized outputs align with ongoing chats.
  • 👤
    Bio Personalization: Adapts prompts based on custom user bio directives (industry, role, style) to match unique workflows.
  • 🎭
    Tone Selection: Quickly toggle prompt results between Professional, Friendly, Concise, and Persuasive tones.
  • 💳
    Payments & Invoicing: Fully integrated pricing grids, subscriptions, and billing alerts powered by Razorpay checkout workflows.
  • 🐳
    Cloud Pipelines: Scalable backend microservices built with Python / FastAPI and deployed via Docker on Google Cloud Run.
