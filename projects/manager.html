About The Manager

The Manager is a self-hosted project cockpit built specifically for developers to centralize administrative coding tasks. It replaces fragmented notes, spreadsheet trackers, and environment logs with a unified operations dashboard. Fusing a Next.js 15 App Router interface with a FastAPI backend, it runs entirely containerized under Docker Compose.

The core user experience is centered around a keyboard-first Omnibar (`Ctrl+K`). This Omnibar supports quick commands (e.g. `/p` for new project, `/t` for new task) and advanced filtering symbols. Additionally, the Omnibar houses a natural language AI parser powered by Groq Llama 3.3. This AI service analyzes natural sentences (like "Create a high priority backend bug fix task for MedTrack estimate 45m") and automatically commits structured project objects to the PostgreSQL database.

Key Modules & Features

  • ⌨️
    Omnibar Command Engine: Keyboard-driven utility supporting fast commands, parameter filters, and navigational paths.
  • 🤖
    AI Query Processing: Natural language processing via Groq API (Llama 3) converting sentences directly into database actions.
  • 🔑
    Developer Vault: Centralized credentials directory storing API keys, configurations, and active port registries.
  • 📈
    Workflow Triage: Tracks task priority matrices (P0/P1/P2) and features automatic AI category classification.
  • ⚙️
    Environments Control: Monitors active server setups, handles variables logs, and logs database backing metrics.
  • 📊
    AI Operations Manager: Tracks active LLM system prompts, monitors token windows, and logs API billing burn rates.
